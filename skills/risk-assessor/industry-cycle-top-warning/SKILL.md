# 产业周期顶部预警

## 触发条件
每周对重点跟踪行业执行一次，或当事件分析触发时执行。

## 五个见顶信号
1. **盈利增速跌破30%**
2. **增速较高位回落超过50%**
3. **拥挤度 ≥ 0.8**（高度拥挤）
4. **估值分位 ≥ 80%**（高估区域）
5. **成交额占比接近20%**（板块吸筹率预警线）

## 输出格式
```json
{
  "sector": "半导体",
  "level": "红色预警",
  "action": "立即减持",

    "PE分位92%（>80%）"
  ],
  "signal_count": 4,
  "top_type": "景气兑现型",
  "confidence": 0.88
}
```

## 历史见顶规律参考
- 产业赛道见顶四种类型：景气兑现型、估值透支型、流动性冲击型、逻辑证伪型
- 两个经验阈值：盈利增速跌破30%；增速较高位回落幅度超过50%
- 拥挤度3分或4分略领先行业指数阶段性高点
