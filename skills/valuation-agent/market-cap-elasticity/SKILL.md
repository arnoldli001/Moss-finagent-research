# 市值弹性测算

## 触发条件
当估值计算完成后触发。

## 执行步骤

### Phase 1：EPS弹性计算
- 产能扩张、价格敏感度、份额提升

### Phase 2：PE弹性计算
- 业务纯度、市值大小、预期差

### Phase 3：市值弹性
- 市值弹性 = EPS弹性 × PE弹性
- 输出弹性评分和上涨/下跌空间
