# 估值方法适用性与情景假设模板

> 供多方法估值计算技能引用。多方法结果分歧大时输出区间而非单点目标价，并说明分歧来源。

## 估值方法适用性表

| 方法 | 适用对象 | 关键步骤/参数 | 不适用情形 |
|------|----------|---------------|------------|
| DCF | 现金流稳定、可预测的公司 | FCFF预测3-5年 → WACC取8-12%区间 → 永续增长率取2-3% → 折现求内在价值 | 强周期、现金流剧烈波动、早期亏损公司 |
| PE | 盈利稳定的成熟公司 | 可比公司PE、自身历史PE分位，剔除一次性损益 | 亏损、盈利剧烈波动公司 |
| PB | 周期股、银行等金融机构 | 每股净资产为锚，结合ROE与PB分位 | 轻资产、净资产失真公司 |
| PS | 亏损成长股、高营收增速公司 | 营收增速与毛利率匹配的可比PS | 营收无增长或商业模式不清晰 |
| PEG | 高增长公司 | PEG = PE/(未来2-3年净利润复合增速)，PEG < 1 偏低估 | 增速不可持续或负增长公司 |

## 情景分析三档假设模板

| 情景 | 需求增速假设 | 利润率假设 | 用途 |
|------|--------------|------------|------|
| 保守 | 低于一致预期（如需求增速取下行阈值，周期股按萧条期量价） | 利润率回落至历史低分位 | 压力测试，给出估值下沿 |
| 基准 | 一致预期或行业中性增速 | 维持当前或历史中枢利润率 | 目标价主锚 |
| 乐观 | 供需缺口扩大、渗透率加速（取上行阈值） | 利润率扩张至历史高分位 | 给出估值上沿 |

## 约束规则

- 至少使用两种以上方法交叉验证；DCF必须同时给出WACC与永续增长率敏感性。
- 各方法权重须说明依据，不得只采用结果最有利的方法。
- 最终输出：合理估值区间（低/中/高）+ 目标价 + 相对现价空间，附全部假设与数据来源。
