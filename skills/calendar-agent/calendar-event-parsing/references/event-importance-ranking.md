# 日历事件优先级基准

## 优先级总表

| 事件类别 | 影响范围 | 基准优先级 | 说明 |
|---------|---------|-----------|------|
| 财报 | 个股/行业 | 高（权重股）/中（一般个股） | 龙头财报对全行业具有定价基准效应 |
| 解禁 | 个股 | 中 | 解禁比例大或解禁市值占流通市值高时升级为高 |
| 会议 | 个股 | 低-中 | 常规股东大会为低，含重组/增发议案时升级 |
| 宏观 | 全市场 | 高/中 | 见专项规则清单 |
| 行业 | 行业 | 中 | 展会、政策发布窗口临近时升级 |

## 事件专项规则
- 解禁：解禁比例（解禁股数/总股本）>5%为高优先级，同时标注解禁市值占流通市值比。
- 宏观数据：PMI、CPI、利率决议（央行/美联储）为高优先级；其余经济数据为中等优先级。
- 财报：同一交易日多只权重股财报时，按市值降序取前3只标注高优先级。

## 使用说明
- 当日事件优先于未来一周事件；同一优先级内按影响范围从全市场到个股排序。
- 优先级仅决定关注顺序，不代表涨跌方向；方向由预期差分析与情感分析补充。
- 高优先级事件必须在日历输出中附带 needs_attention 标记。
