# 政策传导路径分析

## 触发条件
当政策力度评估（policy-intensity-assessment）完成后自动触发。
应在强度评分输出后、产业链瓶颈识别启动前执行。

## 执行步骤

### Phase 1：解析政策工具类型
- 复用力度评估输出的政策类型（财政补贴/税收优惠/准入管制/政府采购/标准制定）
- 提取政策条款中的资金规模、税率、审批、采购、标准等关键要素
- 明确各条款对应的传导机制（需求刺激/成本改善/供给收缩/订单落地/格局重塑）

### Phase 2：映射受影响行业列表
- 基于政策主题匹配直接受益行业
- 沿投入产出关系识别间接受益环节（上游原材料与设备采购关系）
- 识别因标准提高、供给收缩或替代关系而受损的行业与环节

### Phase 3：沿产业链推导受益/受损环节
- 按产业链图谱逐环节标注受益（+）/受损（-）/中性（0）
- 区分环节的受益逻辑：订单放量、价格弹性、份额提升、成本下降
- 每个环节必须引用对应政策条款作为依据

### Phase 4：输出时间维度
- 短期（1-3月）：情绪与订单预期驱动
- 中期（3-12月）：业绩兑现与产能建设驱动
- 长期（1-3年）：格局重塑与渗透率提升驱动

### Phase 5：置信度评分
- 按传导链路的条款依据充分性打分（0-1）
- 多源印证（政策原文+行业数据）可提升置信度
- 置信度低于0.7时标注“需人工复核”

## 约束规则
- 传导路径必须可追溯到具体政策条款，禁止跳步推导
- 无依据环节不得臆造，宁可留空也不得编造受益逻辑
- 置信度低于0.7时标注“需人工复核”
- 本技能仅输出政策影响分析，不构成投资建议
