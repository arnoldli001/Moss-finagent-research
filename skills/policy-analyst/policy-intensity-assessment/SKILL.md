# 政策力度评估

## 触发条件
当系统接收到新政策文件（国务院、发改委、工信部、地方政府发布）时自动触发。
应在政策采集Agent完成标准化后、产业链传导Agent启动前执行。

## 执行步骤

### Phase 1：政策分类
根据政策工具类型分类：
- **财政补贴**：直接资金支持，刺激需求
- **税收优惠**：三免三减半、研发加计扣除，改善盈利
- **准入管制**：牌照发放、审批放宽或收紧，改变供给
- **政府采购**：政府直接购买，创造需求
- **标准制定**：技术标准、行业规范，重塑格局

### Phase 2：政策级别判断
- **发布机构**：国家级（国务院/中共中央）/ 部委级 / 地方级
- **政策措辞**：培育（偏初期）/ 推动（解决规模化工程问题）/ 大力发展（产业爆发机会）
- **政策力度**：培育=1星，推动=3星，大力发展=5星

### Phase 3：影响路径分析
按照“政策工具→行业→产业链→公司”路径分析：
1. 识别直接受益行业
2. 沿产业链推导间接受益环节
3. 判断受损行业和环节
4. 标注时间维度：短期（1-3月）、中期（3-12月）、长期（1-3年）

### Phase 4：强度评分与置信度
- 输出强度评分（1-5星）
- 输出置信度（高/中/低）
- 标注数据来源和可追溯性

## 输出格式
```json
{
  "policy_level": "国家级",
  "policy_intensity": 5,
  "policy_type": "财政补贴",
  "affected_industries": ["固态电池", "锂电材料", "设备制造"],
  "benefited_industries": ["固态电池", "上游材料", "设备"],
  "harmed_industries": [],
  "impact_path": "财政补贴→固态电池→上游材料/设备→宁德时代/赣锋锂业",
  "time_horizon": "中长期",
  "confidence": 0.92,
  "source_url": "https://www.gov.cn/...",
  "publish_time": "2026-09-14T08:00:00+08:00"
}
```

## 约束规则
- 政策力度评分必须有明确的措辞依据，不得凭感觉打分
- 影响路径必须可追溯到具体政策条款
- 置信度低于0.7时，标注“需人工复核”
- 不得输出投资建议，仅做政策影响分析
