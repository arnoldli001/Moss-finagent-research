# 情感极性与强度判定准则

## 极性判定

| 极性 | 典型事件 |
|------|---------|
| 正面 | 业绩超预期、中标大单、政策利好、技术突破、回购增持、大额订单签订 |
| 负面 | 业绩暴雷、监管处罚、股东减持、重大诉讼、退市风险、产能事故 |
| 中性 | 例行公告、人事变动、常规经营披露、与主业无关的资产处置 |

## 强度锚点（1-5分）

| 分值 | 判定标准 |
|------|---------|
| 1 | 影响金额占年度营收<1%，且不改变供需格局，市场基本忽略 |
| 2 | 影响金额占营收1%-5%，引发短期股价波动，不改全年盈利预期 |
| 3 | 影响金额占营收5%-10%，或打开新市场，值得关注 |
| 4 | 影响金额占营收>10%，或改变细分市场供需格局，可能改变短期趋势 |
| 5 | 改变公司中长期成长逻辑（新增长曲线、牌照或技术壁垒变化） |

## 反例提醒
- 利好出尽：业绩兑现但股价已提前充分反应，事件本身为中性甚至负面，不得机械按“业绩超预期=正面”处理。
- 金额幻觉：招标/中标金额占公司年度营收比例过小（<1%）时，强度不得高于2分。
- 陈旧信息：重复披露的历史利好不重复计分。
- 强度与极性独立评估：负面事件也可能只有1-2分的弱影响。
