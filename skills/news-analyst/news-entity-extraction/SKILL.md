# 新闻实体抽取

## 触发条件
当新闻采集Agent完成数据采集并标准化后自动触发。
使用Qwen2.5:1.5B模型，利用其高吞吐能力（60+ tok/s）批量处理。

## 执行步骤

### Phase 1：公司名称与股票代码提取
- 识别新闻中提及的所有公司名称
- 映射到标准股票代码（A股/港股/美股）
- 处理简称、别称、品牌名到公司实体的映射

### Phase 2：事件类型识别
按以下分类体系识别：
- **业绩类**：业绩预告、业绩快报、年报/季报发布
- **交易类**：中标、合同签订、股权转让、并购重组
- **风险类**：减持、诉讼、监管处罚、退市风险
- **资本类**：增发、回购、分红、股权激励
- **经营类**：产能扩张、新产品发布、客户拓展

### Phase 3：关键金额与日期提取
- 提取合同金额、中标金额、减持比例等数值
- 提取事件发生日期、生效日期、截止日期
- 金额统一转换为人民币万元/亿元

### Phase 4：输出结构化JSON
```json
{
  "companies": [
    {"name": "宁德时代", "code": "300750.SZ"},
    {"name": "赣锋锂业", "code": "002460.SZ"}
  ],
  "event_type": "合同签订",
  "event_subtype": "中标",
  "amount": 150000,
  "amount_unit": "万元",
  "event_date": "2026-09-14",
  "summary": "宁德时代中标某储能项目，合同金额15亿元"
}
```

## 模型配置
- 模型：Qwen2.5:1.5B-Instruct-Q4_K_M
- 生成速度：60+ tok/s
- 适用场景：批量处理海量新闻，快速抽取结构化信息
- 不适用：需要复杂推理的判断任务
