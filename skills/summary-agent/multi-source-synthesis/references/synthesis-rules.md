# 多源冲突仲裁规则

> 供 multi-source-synthesis 技能引用，定义多Agent结论聚合与最终预警生成规则。

## 仲裁规则

| 编号 | 规则 | 说明 |
|------|------|------|
| R1 | 置信度加权 | 各Agent结论按 confidence 加权汇总，风险与机会评分的加权结果作为综合判断基础 |
| R2 | 时间维度优先 | 短期高风险压过中期高机会时，预警类型取"风险"，预警等级取两者中较高者 |
| R3 | 一致性加成 | ≥3个Agent结论同向时，最终置信度上调0.05（上限1.0），输出须注明已加成 |
| R4 | 受益与风险个股分列 | 受益个股与风险个股分别输出，不得混合在同一列表 |
| R5 | 预警字段完整 | 最终预警必含：类型/等级/标题/描述/评分/个股列表/影响行业/触发时间 |

## 冲突处理示例

- 风险评估输出高风险（confidence=0.82），机会评估输出高机会（confidence=0.86），且风险影响集中于短期（1-3月）：
  - 按R2：预警类型=风险，预警等级=high
  - 按R1：综合置信度按两者confidence加权
  - 按R4：受益个股与风险个股分列，风险侧注明回避理由
- 政策、新闻、产业链分析同向看多且无短期高风险：按R3上调置信度后输出机会预警

## 输出完整性校验清单

| 字段 | 要求 |
|------|------|
| alert_type | risk / opportunity |
| alert_level | high / medium / low |
| title / description | 概括触发事件与核心判断 |
| risk_score / opportunity_score | 0-100，附加权来源 |
| affected_stocks | 分列受益与风险，含 code/name/impact/reason |
| affected_industries | 影响行业列表 |
| trigger_time | ISO8601带时区 |
| confidence | 0-1，注明是否应用R3加成 |

## 使用说明
- 最终结论必须引用所有使用的数据ID与推理路径，满足数据溯源规范
- 冲突无法仲裁（证据互相矛盾且置信度接近）时，标注"需人工复核"并输出双方依据
