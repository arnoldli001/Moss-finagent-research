# A股流动性周期与板块轮动 Skill

## 0. 触发场景（条件触发，命中即调用）

出现以下任一类问法时，**必须**调用本 Skill 的数据与规则（Supervisor 规则式
`append_liquidity_indicators()` 确定性追加，LLM 规划漏选也会兜底）：

| 问法类型 | 典型表述 |
|---|---|
| 大盘预测 | "大盘怎么看""A股后市""明天大盘涨还是跌""预测明日A股" |
| 复盘分析 | "复盘一下今天股市""今日行情总结""市场为什么涨/跌" |
| 个股买卖建议 | "XX股票能买吗/该卖吗""短线操作建议""加仓还是减仓""止损位" |
| 板块交易策略 | "XX板块怎么操作""板块轮动方向""这个题材还能追吗""低吸还是追高" |
| 仓位/持有期 | "仓位建议""持有3-6个月收益预期""现在几成仓合适" |
| 流动性关键词 | 成交额、放量/缩量、两融、北向、换手率、估值分位、美联储降息、炸板率、拥挤度 |

**中观优先规则**：回答上述问题时，先看钱在哪——**两市总成交额 + 上证（沪市）+
创业板 + 科创板三市分项成交额**，再谈板块与个股。总量定仓位，分项定轮动方向：

- 创业板/科创板成交额占比抬升 → 风险偏好回升、成长风格占优；
- 沪市（上证）占比抬升而双创缩量 → 资金偏向权重/红利防御；
- 双创内部：科创综指（全板口径）比科创50（50只权重成分）更能代表科创板真实量能。

系统侧自动行为（无需Agent手工拼装）：`plan_run` 对 stock/industry/full 任务、
以及 macro 任务命中交易意图词（预测/明日/复盘/短线/买卖/交易策略/仓位等）时，
确定性追加大盘流动性7项 + 科创板/创业板板块4项指标；命中"美联储/降息/FOMC/
宏观流动性"等关键词时追加 CME FedWatch。数据经 A01→A02→A03→A04 校验入库后，
由图节点 `liquidity_ctx` 调用纯函数 `assess_liquidity()` 生成结论，以
`hint.market_liquidity` 注入分析层（A08-A16）与 A17 决策层 prompt。

## 1. 核心命题：流动性是A股短期定价的第一变量

A股短期走势由流动性驱动，基本面决定中期方向。流动性牛市中，传统基本面分析难以
解释短期波动，观测资金和情绪变化更能判断行情节奏。流动性框架分三层：

1. **银行间流动性**（DR007 对7天逆回购政策利率的偏离）——央行释放到金融机构的钱，
   DR007 领先 M1 增速约 **9个月**；
2. **实体流动性**（M1 增速、M1-M2 剪刀差）——金融机构流向实体的钱，与市场走势
   相关性高于社融；M1含企业活期+流通现金，活期越多经营扩张动力越强；
3. **股市剩余流动性**（M1-PPI、成交额、两融、北向、换手率）——实体满足必要需求后
   流向资本市场的钱；M1-PPI 与全A市盈率高相关，差值越大越宽松。

**核心规则**：宏观流动性中期向下 + 股市非下行 + 资金流入股市 → 大概率轮动小盘行情；
科技产业催化叠加股市流动性充裕 → 2万亿量级高位震荡轮动行情。

**M1-M2剪刀差板块排序**：负值扩大=资金退潮，板块表现排序为
银行≈煤炭 ＞ 公用≈高速 ＞ 食饮≈医药 ＞ 沪深300 ＞ 地产链≈TMT成长≈券商；
剪刀差收窄=存款活化、居民资金向权益搬家，成长占优。

**货币环境信号表**：

| 指标 | 宽松信号 | 收紧信号 |
|---|---|---|
| DR007 | 低于7天逆回购利率 | 持续高于政策利率 |
| M1增速 | 持续回升 | 持续回落 |
| M1-M2剪刀差 | 收窄（资金活化） | 扩大（资金定期化） |
| M1-PPI剩余流动性 | 正值扩大 | 正值收窄或转负 |

宏观操作三阶段：宽松确认期（降准降息落地+M1回升）加仓成长至70%+；
宽松中后期（M1见顶回落）切红利价值、降至50-60%；收紧初期（剪刀差扩大+DR007上行）
防御（银行/煤炭/公用），仓位30-40%。

## 3. 量能分层与仓位规则

| 两市成交额 | 阶段 | 建议总仓位 | 操作 |
|---|---|---|---|
| > 3万亿 | 活跃市（主线可持续） | 70-80% | 可追主线龙头，持股为主 |
| 2.5-3万亿 | 震荡市 | 50-70% | 降低追高频率，低吸为主 |
| 2-2.5万亿 | 存量博弈（哑铃/跷跷板） | 40-50% | 高抛低吸，硬科技/非科技各1/3+现金1/3 |
| < 2万亿 | 地量冷淡 | 20-30% | 轻仓等放量确认 |

硬警戒线（analyzer 自动生成 risk_alerts）：

- **1.4万亿牛熊警戒线**：成交额跌破触发（对应牛市缩量60%，牛熊转换警戒）；
- **单日脉冲**：当日成交额 ≥ 1.5×MA5；**缩量**：≤ 0.6×MA5；
- **MA10 上穿 MA50**：温和放量右侧确认信号（需与前一日双均线值比较）；
- **成交集中度 ≥ 42% 预警、接近 45% 警戒**（2008/2018/2021 曾提示牛熊转换；
  指标有效性：换手率 > 相对换手率 > 成交额占比）；
- **两融余额5日降幅 ≤ -2%**：杠杆退潮预警；
- **估值分位**：宽基/板块 PE 五年分位 ≥ 80% 偏热预警，≤ 20% 偏冷机会提示。

### 3.1 历史规律（概率性先验，须注明复盘属性，不代表未来必然重复）

- **地量见地价**：近5年地量后 T+20～T+60 存在放量预期，但地量需事后不再创新量低确认；
- **牛市缩量回调**：2005年以来五轮牛市22次缩量回调，六成缩量超50%；40%-70%缩量区间
  是短线较优入场窗口，1/3个月后上涨胜率均 >60%；跌破1.4万亿例外；
- **放量后演绎**（14/12、15/5、19/2、20/7、24/10、25/8 六次典型放量）：
  1个月内小盘占优、风险不大；3个月多转盘整（回撤4-8%）且放量前主线难延续；
  6个月分化，仅产业逻辑最硬方向能延续强势；
- **缩量健康度**：缩量暴涨=筹码锁定最健康；次日缩量低开企稳=洗盘继续持有；
  次日放量低开续跌=动能衰竭止损；
- **缩量必轮动**：板块间与题材内强势股双轮动，**切勿追当天强势股**；
- **哑铃（红利+微盘）**在经济收缩+低通胀下最有效；利率上行、明确成长主线、
  拥挤交易崩溃、红利权重基本面恶化时失效。

## 4. 板块轮动规则（中观层）

### 4.1 轮动速度与阶段

- 市场大致以 **2-3周** 为周期完成一轮风格切换；主线行情结束后的快速轮动阶段
  持续中枢约2-3个月（历史平均约107天），之后关注财报季等节点；
- 资金集中推动主线时轮动放缓；指数上行后期风格切换加速。

### 4.2 拥挤度指引

板块拥挤度近一年分位接近100% → 短期交易过热、领涨钝化，资金向低拥挤方向切换；
拥挤度充分回落后原强势板块更易成为下一轮承接方向。结合 `mkt:cybkcb:val:all`
的板块PE分位判断双创冷热（PE分位≥80%偏热、≤20%偏冷）。

### 4.3 跷跷板战法（缩量轮动行情专用）

1. 仓位分三份：1/3硬科技、1/3非科技（红利/消费）、1/3备用现金；
2. 硬科技冲高减仓兑现，切入防守型非科技；
3. 非科技轮动到高点再切回硬科技；
4. 全程低吸不追高，不追当天强势股。

### 4.4 产业链扩散路径

高位方向涨多必分化，资金沿产业链向低位关联环节扩散。例：电力→算力→硬件→
PCB/散热。跟着产业链逻辑找低位关联方向，比跟着涨幅追高胜率高。

### 4.5 市场宽度（spot_summary）解读

- 上涨家数占比 >60% 且中位数为正：普涨情绪健康；
- 指数涨但上涨占比 <40% / 中位数为负：权重拉指数、个股赚钱效应差，警惕虚涨；
- 上涨占比连续低于30%：情绪冰点，结合地量规律等待放量反转。

## 5. 个股买卖判断

### 5.1 量价关系九句口诀（个股成交量价可由行情库就地计算）

| 口诀 | 含义/动作 |
|---|---|
| 高位放量要跑 | 涨一大段后成交量放大1-2倍却滞涨/收阴，九成是主力出货，先减仓 |
| 低位放量要跟 | 长期下跌横盘缩量后明显放量，底部启动信号，敢于跟进 |
| 高位无量要拿 | 高位缩量筹码稳、主力未走，继续持有 |
| 低位无量要捞 | 低位无人问津的缩量是悄悄吸筹区 |
| 量增价升要进场 | 最健康形态，真金白银推动，顺势加仓 |
| 量增价跌赶紧离场 | 放量下跌最危险，不抄底 |
| 量缩价升要持有 | 卖盘轻、控盘度高，不轻易下车 |
| 量平价跌要出局 | 无量阴跌温水煮青蛙，止损 |
| 量平价升要加仓 | 温和放量稳步上行，筹码锁定 |

### 5.2 缩量回调后的两个买入信号

1. **单日脉冲放量大阳线**：高赔率，确认日尾盘小仓介入，次日看持续性加仓；
2. **成交额MA10上穿MA50温和修复**：偏右侧，上穿当日加至目标仓位。

### 5.3 炸板率情绪温度计（数据源未接入时不得编造数值）

炸板率 = 当日炸板股数 ÷ 涨停总数，比涨跌幅更真实：
>40% 减仓等修复；<20% 可积极参与；从高位骤降=情绪修复右侧。
当前系统未自动接入，使用须显式声明数据缺口或由信息层从公开报道提取并标注溯源。

### 5.4 流动性环境×个股策略

| 环境 | 成交额 | 个股策略 | 仓位 |
|---|---|---|---|
| 宽松活跃 | >3万亿 | 追主线龙头，持股不动 | 70-80% |
| 温和宽松 | 2.5-3万亿 | 低吸高抛，板块轮动 | 50-70% |
| 存量博弈 | 2-2.5万亿 | 哑铃+跷跷板轮动 | 40-50% |
| 地量冷却 | <2万亿 | 轻仓等放量确认 | 20-30% |

单票仓位不超过总仓位15%。

```json
}
```

分析层/决策层使用要求：

1. **中观研判顺序**：先引两市总量与阶段 → 再引上证/创业板/科创板三市分项与占比
   （判断风格偏权重还是偏成长）→ 再给板块轮动与个股结论，禁止跳过量能直接推标的；
2. 结论必须引用上述具体数值与日期，禁止空泛表述；仓位建议与
   `suggested_position_pct` 一致，偏离须给基本面理由；
3. 缩量阶段（<2.5万亿）的板块建议必须遵守跷跷板/低吸不追高规则，并结合
   `market_breadth` 判断赚钱效应虚实；
4. `data_gaps` 必须在报告"数据局限"如实转述，**禁止把缺口反转为多空判断**；
5. 持有期收益按 A17 schema 的 `expected_return_3_6m` 输出 bull/base/bear 三档
   情景与触发假设，禁止精确点位/精确收益率承诺；`invalid_signals` 列失效条件；
6. 所有输出附带免责声明，历史规律标注为复盘总结、不代表未来。
