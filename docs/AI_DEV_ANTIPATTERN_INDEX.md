## 0. 一句话

> **AI 编码的缺陷有两类来源：一类是"手"（语法/编辑/并发写），一类是"脑"（归因/判据/理解）。**
> "手"的这类必须用**判据**挡（不是提醒）；"脑"的这类必须用**换仪器 / 换层 / 换载体**根治 ——
> 提醒和"下次注意"对这两类都无效。

本轮统计（2026-09-28 ~ 09-30，含并发协作者）：

| 类别 | 次数 | 我用什么挡住的 |
|---|---|---|
| **语法/编辑类自伤**（长中文里混 ASCII 引号） | **11 次** | 判据 `test_cjk_quote_safety.py` + **外置 `.md` 载荷**（根治） |
| **形状判据假绿** | 1 次 | 改成**行为**判据（真发一次请求） |
| **假红**（编辑时序 / 缓存污染） | 2 类 9 条 | 纪律「改文件期间不跑套件」+ conftest 全局清缓存 |
| **误归因**（受害者当犯人、代理量当因果） | 3 次 | 换仪器（在飞点名）+ **可复现重放** |
| **判据维度缺失**（慢/错/崩/静默/越权/类型/作用域） | 3 次 | 维度闸门（§1）+ 本轮新增**类型维**与**作用域维** |
| **共享资源冲突**（号撞车 / 共享文件被写坏 / 真进程被停） | 5 次 | 号现读 + 形状自检 + **活着的 PID 一律拒发信号** |

## 3. 「下次如何避免」三段 checklist

### 3.1 动手前（10 秒）

1. **指代复述**：指令里有"前者/后者/那条"吗？→ 先复述再执行。
2. **清单优先**：用户说"彻底/都/全"吗？→ 先产清单 + 排序 + 依据。
3. **同类资产**：这个诉求仓库里是不是**已经有** skill/脚本/入口？（有 ⇒ 扩写，不新建）
4. **载体选择**：这次要写长中文吗？→ 写进 `.md`，**别写进 Python 字符串**。
5. **作用域枚举**：这次改动会作用到"所有 X"吗？→ 先列 X 的清单（HTTP/WS/CLI/作业/lifespan）。
6. **维度预告**：这条改动可能造成 **慢/错/崩/静默/越权/类型漂移/作用域遗漏** 哪几维？各打算怎么量（"没量到"也要写）。

### 3.2 动手时

7. **判据看电流**：别断言"结构存在"，要断言"副作用发生了"。
8. **类型也是契约**：用到 `==` 比较响应体时，问一句"类型错了会不会也相等"。
9. **多入口**：改"能不能做"的判断时，把所有触发路径列全（定时/手工/补偿/旁路）。
10. **改文件期间不跑套件**（或跑完复跑）；`file changed since it was read` ⇒ 重读再改，不绕过工具。
11. **号现读**：写台账/PRD 前现读最大号 +1（并发协作者随时在落号）。
12. **长文本外置**：注册脚本一律「读 `.md` → 插入」，不在脚本里写长中文。
13. **共享文件改完跑形状自检**（`^## ` 序列 + `--ledger`）。

### 3.3 收尾前（交付自检，答不出就是没交付）

14. 这一类**下次怎么不可能再发生**？**判据叫什么名字**？
15. 判据**覆盖了哪几维**？哪一维"没量到"，写出来了吗？
16. 有没有**假绿**（结构绿、功能没生效）？有没有**假红**（源码/环境在我跑测期间变过）？
17. 我的**根因**是实验结论还是相关性猜测？**反例**跑过吗？能**可复现重放**吗？
18. **归属**写清了吗（哪些我做、哪些协作、哪些没做完）？
19. 长文本用的是**代码字符串**还是**外置载荷**？
20. 交付物里**有没有"看起来像完成"的半个结论**（例如"已由 worker 负责"却没说 worker 在不在）？
