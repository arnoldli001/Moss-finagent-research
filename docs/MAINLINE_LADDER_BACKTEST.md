# 告警后买入：止损 −7% + 浮盈每 +10% 减仓 30% 的板块平均盈亏

> 由 `scripts/ladder_backtest.py` 生成（只读，告警表 `mainline_alert`）。
> 只取 🔴强 + 🟡中；买入价 = 告警日收盘。共 1963 条 / 135 个板块。

## 规则与假设

- **止损**：最低价 ≤ 买入价 × 0.93（−7%）→ 剩余仓位全部按该价成交。
- **止盈阶梯**：最高价 ≥ 买入价 × (1 + 10% × k) → 卖出一档。
- **口径 A（主）**：每档卖**初始仓位**的 30% —— +10/20/30% 各卖 30%、+40% 卖完剩下的 10%（这才符合「直到卖完」）。
- **口径 B（对照）**：每档卖**剩余仓位**的 30%；剩余按 0.7 递减永不归零，最多走 15 档。
- **同日既触止损又触止盈 → 先止损**：日线看不出盘中顺序，选保守方向（低估收益、高估止损次数）。
- **未平仓**：数据走完仍未卖完的，按最后一根收盘价盯市；单独计数，不丢掉（丢掉会偏向已走完的那批）。
