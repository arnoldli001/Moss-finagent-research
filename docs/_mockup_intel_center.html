热度与异动
热度分 = Σ(条目可信度) 按板块归一
环比 = 今日提及量 / 20日均值 − 1
异动阈值 = 环比 ≥ +200% 且 提及量 ≥ 10
分位 = 近 6 年 同日指标的百分位
全部为描述性统计：回答"多少条、比平时多多少"， 不回答"会不会涨"。
为什么只给统计量：把「主观评价词」换成「提及量 27 次 / 均值 9 次」， 使用者获得的信息不减反增 —— 因为判断阈值由他自己定。
共振判定
1. 按事件轴聚类 # 同事件多帖算1源
2. 统计独立来源数 # 转载不计
3. 校验方向一致性 # 不一致→指标不一致
4. 加权可信度 ≥65 且 独立源 ≥2 → ⭐2
5. ≥3 个类型（含平台指标）→ ⭐3
必须查重的理由：同一份信息被当成三份独立证据，共振就是假的。 本项目主线挖掘模块已就此事写明过风险，此处复用同一口径。
日历因子 · 影响范围
覆盖家数 = COUNT(受影响标的)
行业分布 = GROUP BY 申万二级 # 不用概念板块
占比 = 事件规模 ÷ 该行业流通市值
密集度 = 已预约家数 ÷ 行业公司总数
确定性 = 规则确定 | 公司预约·可改期
「确定性」这一项是日历独有的：
· 解禁日由交易所规则确定，不会变；
· 财报披露日是公司预约，会改期 —— 所以界面把 「已改期 N 次」单独标出来，改期本身就是一条提示。
为什么不做"事件→涨跌"映射：那是预测，属投资建议范畴。 这里只回答「哪些标的被覆盖、覆盖多重」，方向由使用者自行判断。

弹窗文案统一为「某条公开信息已出现」的事实通知； 按钮是"查看依据" —— 列出的是来源大类与可信度构成， 不暴露具体数据源（详见下方「来源保密」说明）。
来源保密（平台核心资产）
接口响应中不存在 source_url / group_id / author / 采集器名； 前端只显示来源大类（官方 / 研报 / 媒体 / 自媒体 / 未证实）， 不显示具体机构名、媒体名或账号。
原因：来源本身可被复制 —— 暴露即失去信息差壁垒。
弹窗抑制（防打扰）：同一事件 2 小时内不重复弹；可信度 <65 不弹； 非交易时段仅 ⭐3 弹。今日实际弹窗 3 次，抑制 15 次。
共振判定规则
1. 按事件轴聚类 # 同事件多帖算1源
2. 统计独立来源数 # 转载不计
3. 校验方向一致性 # 不一致→指标不一致
4. 加权可信度 ≥65 且 独立源 ≥2 → ⭐2
5. ≥3 个类型（含平台指标）→ ⭐3
为什么必须查重：同一份信息被当成三份独立证据，共振就是假的。 本项目主线挖掘模块已就此写明风险 —— 同一口径在这里复用。

关键设计取舍
盘前预测的数据基准：昨日收盘 + 隔夜信息
输入 = 上一交易日收盘（结构 / 资金 / 拥挤度等指标） ＋ 隔夜增量（美股 / 外盘商品 / 盘后公告 / 新增研报）。 不含本日盘中数据，界面固定显示基准日期。
为什么 15:15 还要采一次？
收盘后的内容是次日盘前预测与简报的主要输入。不采这一次， 次日 08:05 那次要在 20 分钟内交出全部内容，压力集中且容易超时。
超时保护：所有盘前任务硬超时 08:28，超时则标注 「输入不完整」并列出缺失项，不用估算值补齐。
