# 拥挤度水位：为什么要求 750 根日线，不足的板块怎么算

> 触发问题：`404/750 数据不足`（= `886099.TI AI智能体`）。
> 本文回答三件事：750 是哪来的、它有没有解决问题、专业领域怎么做。

## 一、750 的口径与来历

**水位定义**（`src/sector_crowding/__init__.py:3`）：

```
水位 = MA5(板块成交额 / 全市场成交额) / max(该比值在【近 6 年】内的最大值)
```

分母是**该板块自己**近 6 年（≈1460 个交易日）的平滑拥挤度最大值，
且**逐日 expanding**（第 i 天只看到第 i 天为止，避免未来函数）。

**750 的理由**（`sector_crowding/config.yaml:29-35`，项目自己写的）：

> 对只有半年历史的新板块，它自己的"历史最高"就是最近这几天
> —— 于是水位**恒为 100%**，一上线就误告警。
> 实测（2026-09-18 首次全量回填后）：`min_bars=60` 时有 218 个板块 ≥80%、
> 其中 101 个 ≥90%，绝大多数是这类"历史太短所以永远是自己最高"的板块。
> 要求至少 3 年，分母才覆盖得上一轮完整涨跌周期。

所以 750 ≈ 3 个交易年 = 分母窗口（6 年）的**一半**。

## 二、真实机制：这是「样本最大值偏差」，不是"数据不够"

水位是个**极差归一化**（range normalization），分母是一个**样本最大值** `M_n`。

次序统计量的基本结论：**`E[M_n]` 随 n 单调上升**（轻尾分布下约
`μ + σ·√(2 ln n)`；重尾下增长更快）。

于是：

| 板块历史 | 分母 | 后果 |
|---|---|---|
| n 小 | `M_n` 系统性偏小 | 水位**系统性偏高** → 误告警 |
| n 大 | `M_n` 接近真实极值 | 水位正常 |

项目用 `min_bars=60` 时那 218 个误告警，就是这个偏差的实证。
**750 的直觉是对的：让所有板块的分母都来自"样本量足够大"的同一档。**

### ⚠️ 但 750 只是把悬崖挪了个位置，没有消除偏差

实测（2026-09-27）：

```
板块日线根数分布（2510 个板块）
      0~125       87
    125~250      501
    250~375       11
    375~500      223
    500~625      134
    625~750       64
    750~1000     220
   1000~1250     407
   1250~1500     863
      >=1500       0

750~1460 根（分母样本量不足 6 年）: 1033
>=1460 根（分母样本量满 6 年）    :  457
```

**1033 个板块的分母样本量在 750~1460 之间浮动，`E[M_n]` 仍随 n 上升。**
即：一个 800 根的板块和一个 1460 根的板块，分母口径**仍然不等价**，
水位仍有系统性偏差 —— 只是比 60 根时小。

粗估量级（高斯近似，`μ/σ≈5`，仅示意）：

| 历史根数 | `E[M_n]` 相对 6 年满窗的偏低 | 水位被抬高 |
|---|---|---|
| 60 | ~12% | ~12% |
| 404 | ~4% | ~4% |
| 800 | ~2% | ~2% |
| ≥1460 | 0 | 0 |

⚠️ 成交额占比是**右偏重尾**，真实偏差比高斯近似更大；
上表只用于说明"偏差随 n 连续变化"，不是精确值。

**结论：750 是二值 cliff，而问题是连续偏差。二值门槛必然两头不讨好
—— 749 根全废，750 根全量采纳，而 800 根与 1460 根仍不等价。**

## 四、专业领域的六种做法

### A. 回溯补齐（backcast）—— 指数行业的标准做法 ★最有效

概念板块由成分股定义，而**成分股有很长的历史**。用当前成分股的历史成交额
回填板块成交额：

```
board_amount(t) = Σ_{i ∈ members} stock_amount(i, t)
```

中证 / 国证 / 中债 等机构发布**新指数**时的标准做法就是"回溯计算至基日"，
并在方法论里**明确披露**。

- ✅ 直接补齐分母窗口，33 个板块立刻可用
- ⚠️ **前视偏差**：今天的成分 ≠ 当年的成分（`sources.py:8` 已承认）。
  但对**分母（历史极值）**而言，成分漂移的影响远小于对**信号**的影响
- ✅ 建议：回填行打 `backcast=True` 标记，前端区分"实测 / 回溯"

### B. 收缩估计（shrinkage / 经验贝叶斯）★最适合现在做

把分母估成"自身极值"与"同类极值"的加权：

```
w = n / (n + k)                     k ≈ 250（可标定）
denom = exp( w·ln(M_own) + (1-w)·ln(M_peer) )
```

- `M_peer` = 同类型（概念板块）近 6 年最大值的**中位数**
- 404 根 → `w = 404/654 = 0.62`；38 根 → `w = 0.13`（几乎全靠先验）
- ✅ **连续**，没有 cliff；把 750 以下的板块救回来
- ✅ 同时**消除 750~1460 的残余偏差**（n 越大越信自己的极值）
- ⚠️ 引入横截面耦合：某板块的水位会依赖同类整体水平（这是特性不是 bug）
- 📌 这正是 James-Stein / 分层贝叶斯在因子工程里的标准用法

### C. 次序统计量 / 极值外推校正

显式把 `M_n` 外推到参考样本量：

```
denom_corr = M_own · b(N_ref) / b(n),   b(n) ≈ √(2 ln n)
```

- ✅ 不引入横截面耦合，统计上有据
- ⚠️ 依赖分布假设；n < 100 时不稳
- 适合作为 B 的替代或交叉验证

### D. 横截面分位（cross-sectional percentile）

不放"对自己历史的相对位置"，改放"当天在所有板块中的排名"：

```
pct(t) = rank(x_t) / N_t
```

- ✅ 零历史要求，新板块天然可用；多因子模型的标配（Barra 类全因子横截面标准化）
- ✅ 可作为**独立一列**与水位并列，两条口径互证
- ⚠️ 语义不同：结构性一直很热的板块会显得"正常"，测不出"自己在极值"

### E. 分档发布 + 覆盖率披露

```
n >= 750        → 正式水位
250 <= n < 750  → 参考水位（用 B 校正分母），前端标「参考」
n < 250         → 不出水位，出横截面分位（D）
```

- ✅ 最诚实：不假装有把握，也不把信息丢掉
- ✅ 前端已经在显示 `404/750`，这条路只差"分级"这一步

### F. 统一分母（全市场 / 同类共用）

所有板块共用一个分母（全市场近 6 年最大拥挤度）。

- ✅ 彻底消除样本量不等价
- ⚠️ 语义变了：从"板块自身的极值"变成"相对全市场峰值"，可比性变差

## 五、建议（按性价比排序）

| 优先级 | 动作 | 代价 | 收益 |
|---|---|---|---|
| **P0** | 上 **B 收缩估计**（k=250 先标定） | 半天，纯本地重算（`recompute_stored_water_levels` 已支持不联网重算） | 33 个板块全部可用；同时消掉 1033 个板块的残余偏差 |
| **P1** | 加 **D 横截面分位**作为独立列 | 半天 | 多一条互相独立的口径，新板块零门槛 |
| **P2** | 上 **A 回溯补齐**成分股历史 | 1~2 天（要拉个股成交额） | 把"数据不足"从产品里彻底删掉；面试里是加分项 |
| **P3** | **E 分档披露** | 前端小改 | 把"参考"与"正式"分开，避免误读 |

**为什么不建议只把 750 调低**：那等于手动选择偏差大小 ——
调低 → 短历史板块水位虚高；调高 → 更多板块被废弃。
**B 用连续权重取代了这个二值选择，是同一件事的正确做法。**

## 六、面试表述（这套思路本身是加分项）

> "我们的拥挤度水位是'相对自己近 6 年极值'的归一化。一开始用 60 根日线就放行，
> 结果 218 个板块报 ≥80%、101 个 ≥90% —— 全是新概念，因为**样本最大值随样本量
> 单调上升**，历史短的板块分母天然偏小，水位系统性虚高。
>
> 我们先加了 750 根（≈3 年）的门槛，但后来发现这只把悬崖挪了个位置：
> 分母样本量在 750~1460 之间仍不等价，1033 个板块还有残余偏差。
> 所以最终改成**收缩估计**：`w = n/(n+250)`，把自身极值向同类中位数收缩，
> 偏差随 n 连续收敛，同时把 33 个新题材救了回来。
> 长期方案是用成分股历史做**回溯补齐**，和指数机构发布新指数的做法一致。"

# 七、已实施（2026-09-27）

## 7.1 ⚠️ 先试了「收缩估计」，**回测证伪，放弃了**

原计划是 James-Stein 式收缩：

```
w = n/(n+k),  denom = exp( w·ln(M_own) + (1-w)·ln(M_peer) )
```

**两轮标定都失败：**

**第一次判据错**（"让 750~1460 组与 ≥1460 组的告警率对齐"）：
任何 `k>0` 都让差距**变大**（6.0% → 10.9% → 13.5%）。
原因是这两组不是"同样的人、数据多少不同"，而是**两个不同样本** ——
组 A 是 3~6 年历史的新板块，其中大量是当下正热的新题材（AI智能体、
固态电池、机器人…），告警率本来就该更高。**真实信号和样本量偏差混在一起，
没法当标定靶子。**

**第二次判据对**（截断回测：同一批满窗板块，假装只有最后 T 根，
拿"用完整 6 年极值算的水位"当真值）—— 结果**收缩一致变差**：

| k | 系统性偏差（T=750 截断） |
|---|---|
| 0（不收缩） | **+0.047** |
| 25 | +0.051 |
| 250 | +0.099 |
| 1000 | +0.283 |

**根因**：`M_peer` 是横截面**中位数**，各板块的 `M_T` 与它比有高有低。
向中位数收缩 = 把**高于中位**的板块分母**调小** → 水位反而更高 → 偏差扩大。
**方向错了：该做尺度校正，不是水平收缩。**

## 7.2 最终方案：尺度校正 `denom = M_n · r(n)`

```
r(T) = median( M_full / M_T )     在满窗板块（n >= 1460）上标定
```

截断回测结果（`scripts/calibrate_shrink_k.py` → `docs/_water_bias_curve.txt`）：

| T | r(T) | 朴素偏差 | 校正后偏差 | MAE 改善 |
|---:|---:|---:|---:|---:|
| 60 | 2.6207 | +0.3502 | **−0.0612** | **54.3%** |
| 120 | 2.3772 | +0.2870 | −0.0618 | 47.2% |
| 250 | 1.7021 | +0.1801 | −0.0241 | 27.0% |
| 375 | 1.3013 | +0.1069 | +0.0092 | 9.9% |
| 500 | 1.1469 | +0.0793 | +0.0288 | 1.3% |
| 750 | **1.0000** | +0.0470 | +0.0470 | 0.0% |
| 1460 | **1.0000** | +0.0002 | +0.0002 | 0.0% |

📌 `T >= 750` 时 `r = 1` 是**实测结论**（多数满窗板块的极值就在最近 750 天内），
不是人为设的 —— 所以 **750 以上的行为完全不变，改动只影响 750 以下**。
