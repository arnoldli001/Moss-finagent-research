# `bar.vol20` 是不是信号：波动率 / 误报 / 真值覆盖对账

> 由 `scripts/head_vol_gate_report.py` 生成，评分表 `mainline_score`。
> 标签 `big`：未来 20 日收盘涨幅 > 10%；「误报」在这里细分为两种：涨不到 10%（空耗）与**反而跌超 10%**（亏钱）。

## 一、风险归一化：它是在解释方差，还是在选股？

把标签换成 `fwd20 / vol20`（波动率归一后的相对表现），再算 `vol20` 的 AUC。若掉回 0.5，说明它只是在解释**方差**。

| 中 | 0.6083 | 0.4882 | 纯方差 |

## 四、在**真实告警集**上加 `vol20` 门限的代价

告警集 = 候选池内 `level ∈ {strong, medium}`（冷却/确认之前的上界）。门限 = 当日池内 `vol20` 分位 ≥ τ。

## 五、怎么读

- 若第一节的「风险归一化 AUC」贴在 0.5，`vol20` 就不是 alpha，把它当门限只是把告警挪到波动更大的板块上：
  P(>+10%) 上去的同时 P(<−10%) 也上去，用户说的「误报」并没有变少。
- 若第四节里 τ 一抬，**漏报**就开始涨，那这个门限的代价是真值覆盖，和抬高绝对分数线是同一个失败模式。
