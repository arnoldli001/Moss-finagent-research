# 面试演示策略

## 一、演示核心原则

面试时，演示重点不是“系统有多完整”，而是“你的技术决策有多合理”。

## 二、演示话术框架（STAR法）

### S（情境）
“在传统量化研究中，因子挖掘和策略验证往往依赖人工，迭代周期长，且容易受到主观偏见影响。”

### T（任务）
“我希望构建一个自动化、可审计的量化投研系统，能够从数据获取到策略生成全链路覆盖，同时保证信号的可解释性和可验证性。”

### A（行动）
“我设计了多Agent协作架构，包含数据层、信息层、分析层、行业层、决策层和审计层。数据层使用AkShare和Tushare获取数据，分析层使用DeepSeek-V4-Flash进行核心推理，本地使用Ollama运行轻量模型处理基础任务。”

### R（结果）
“系统在近10年的回测中实现了XX的夏普比率，最大回撤控制在XX%以内。更重要的是，系统能自动检测回测偏差并生成审计报告，确保策略的可信度。”

## 三、面试官可能追问的问题

### Q1：你的Alpha来自哪里？
**回答**：展示系统中的宏观周期因子（PPI-CPI剪刀差、库存周期定位）和产业链因子，强调这些因子有经济逻辑支撑，而非纯数据挖掘。

### Q2：如何避免过拟合？
**回答**：强调系统采用分样本内/样本外验证，且因子选择有经济逻辑约束。回测使用近10年数据，覆盖2-3轮完整周期。

### Q3：如果实盘失效怎么办？
**回答**：展示系统的排查流程——先检查数据延迟和滑点，再检查市场风格切换，最后才考虑因子衰减。系统内置A18审计Agent自动检测异常。

### Q4：你用了什么回测框架？
**回答**：可以提到Backtrader或NautilusTrader等事件驱动框架，强调你对回测架构的理解。Demo阶段使用自研轻量回测引擎。

### Q5：Token成本如何控制？
**回答**：本地模型处理基础任务零成本，云端API按需调用。使用语义缓存（命中率≥50%），模型路由（简单任务走轻量模型），月成本控制在100-200元。

## 四、演示流程建议

1. **开场（1分钟）** ：项目背景 + 核心价值
2. **架构展示（2分钟）** ：18个Agent分层架构图
3. **核心链路演示（5分钟）** ：
   - 输入“分析当前煤炭行业投资机会”
   - 展示Supervisor调度过程
   - 展示各Agent并行执行
   - 展示投研建议生成
4. **溯源展示（2分钟）** ：点击结论，展示数据来源和推理路径
5. **技术亮点（2分钟）** ：Token优化、缓存、定时任务、自迭代
6. **Q&A（3分钟）**

## 五、技术亮点总结

| 亮点 | 说明 | 面试价值 |
|------|------|----------|
| 多Agent协作 | LangGraph StateGraph + Supervisor调度 | 展示架构能力 |
| 混合模型 | 本地Ollama + 云端API | 展示成本意识 |
| 数据溯源 | 每个数据点携带来源标签 | 展示合规意识 |
| 推理路径 | 完整Trace记录 | 展示可审计能力 |
| Token优化 | 语义缓存 + 模型路由 | 展示工程能力 |
| 自迭代 | EDV范式 + 经验库 | 展示学习能力 |
