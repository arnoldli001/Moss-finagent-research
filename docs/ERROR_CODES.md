# 报错码总表（编码 — 故障 — 修改建议）

> **权威来源**：码定义在 `src/api/error_codes.py`（后端）与 `web/src/errors.ts`（前端文案）。
> 本表是**唯一**把「编码 / 故障根因 / 修改建议」合在一起的运维速查表。
> **维护规则**：新增 `ErrorSpec` 必须同步本表 —— `tests/unit/test_error_handlers.py::test_registry_codes_documented_in_error_codes_md` 会校验，漏了直接挂测试。

响应契约：`{"detail": "用户文案", "code": "层前缀_数字", "trace_id": 可选}`。
4xx 的 `detail.cause` 是 `brief()` 脱敏后的原因；**5xx 永不下发原文**（只进日志）；
422 附 `fields[]`（loc/msg/type，不回显输入）；未捕获异常带 `trace_id` 供日志回查。

## SYS_ 系统层

| 编码 | HTTP | 用户文案 | 故障（根因/场景） | 修改建议 |
|---|---|---|---|---|
| SYS_5000 | 500 | 服务器内部错误，请稍后重试 | 未捕获异常（代码缺陷、依赖损坏） | 拿响应里的 `trace_id` 到后端日志 grep `trace_id=<id>` 定位堆栈；修后 `manage.py start --replace`（注意：会连带重启全部实例） |
| SYS_5030 | 503 | 服务暂不可用，请稍后重试 | 服务重启中 / lifespan 未就绪 / 预热期 | 等 30–60s；`manage.py status` 看进程；持续出现查 `data/run/backend.log` 启动段 |
| SYS_5100 | 500 | 服务尚未就绪 | runtime 未初始化（`build_runtime` 失败） | 查启动日志中 build_runtime 异常（配置缺失/依赖坏）；确认 `configs/` 完整 |

## AUTH_ 认证与权限层

| 编码 | HTTP | 用户文案 | 故障 | 修改建议 |
|---|---|---|---|---|
| AUTH_4010 | 401 | 登录状态已失效，请重新登录 | 未登录 / 会话过期 / 会话库不可用 | 重新登录；后端刚重启后会话失效属预期；忘密码用 `scripts/reset_admin_password.py` |
| AUTH_4030 | 403 | 当前账号没有该操作的权限 | 角色不足 / 租户隔离拦截（TenantError） | 确认账号角色与租户归属；审计日志 `extra.reason` 有脱敏原因 |
| AUTH_4290 | 429 | 操作太频繁了 | 登录/写操作限流 | 等窗口过后再试；排查是否有脚本在重试 |

## REQ_ 请求与参数层

| 编码 | HTTP | 用户文案 | 故障 | 修改建议 |
|---|---|---|---|---|
| REQ_4000 | 400 | 请求参数有误 | 路由手动校验拒绝 | 对照 `docs/API_REFERENCE.md` 对应端点的参数说明 |
| REQ_4040 | 404 | 请求的内容不存在 | ID 不存在 / 任务结果已过保留期被清理 | 确认 ID；回测/分析任务结果有保留期（BACKTEST_RETENTION），过期重跑即可 |
| REQ_4090 | 409 | 当前状态不允许该操作 | 状态冲突（如分析进行中重复提交） | 稍后重试或先终止原任务 |
| REQ_4220 | 422 | 提交的内容未通过校验 | pydantic 请求体校验失败 | 按响应 `fields[]` 的 loc/type 修正字段；输入原文**不回显**是刻意的 |

## DATA_ 数据源层

| 编码 | HTTP | 用户文案 | 故障 | 修改建议 |
|---|---|---|---|---|
| DATA_5020 | 502 | 行情/数据源暂时不可用 | 上游失败：AkShare 反爬、东财 WAF 阻断（会漂移）、腾讯/新浪抖动 | 看数据源健康度面板 `health.rank`；东财只能当链尾备用（已知约束）；等待自动降级链或稍后重试 |

## NET_ 网络层（仅前端本地生成，后端不下发）

| 编码 | 场景 | 故障 | 修改建议 |
|---|---|---|---|
| NET_9001 | fetch reject 且探活失败 | 后端不在运行 | 本机：按页面提示执行 `python manage.py start --daemon --replace`；公网：等待值守自动拉回（≤5 分钟）或联系管理员。运维指令**只在 localhost 显示** |
| NET_9002 | 后端在线但连接被中断 | 浏览器复用了旧连接（后端刚重启常见） | 直接重试一次即可 |

## 附：值守退出码（`manage.py ensure` / MossPilotWatchdog 任务）

| 退出码 | 含义 | 修改建议 |
|---|---|---|
| 0 | 健康（静默）或重启成功 | 无需处理 |
| 2 | 端口被**其他程序**占用，拒绝启动 | **需要人工**：`diagnose_port` 看占用者；非本项目进程绝不能杀 |
| 其它 | 重启失败 / python 起不来 | 查 `data/run/pilot-watchdog.log`（一行摘要）→ `backend_incidents.jsonl`（现场）→ `backend.log`（启动段） |
