# 行业轮动与资金流向监控（sector_rotation）

每个交易日自动产出一份「指数卡片 + 行业热力图 + 主力流向（当日/近5日）+
大盘资金趋势 + 风格轮动 + 规则研判」的报告，落盘 JSON 与独立 HTML，
通过 REST 接口与「资金流监控 → 行业轮动日报」页签对外提供。

## 接口

前缀 `/api/v1/sector_rotation`（鉴权与其它业务接口相同：登录会话 + 租户中间件）。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/report` | 最近交易日报告 JSON（读盘优先；当天尚无报告时同步生成一次，约 20~40s）。`?date=YYYY-MM-DD` 指定历史交易日 |
| GET | `/report.html` | 独立 HTML 报告页（可 iframe / 新窗口打开；前端页签就是嵌的它） |
| GET | `/history` | 已落盘报告的交易日列表 |
| POST | `/refresh` | 强制重新生成（穿透落盘与 TTL；同步执行） |
| GET | ``（根路径） | 模块自检 |

## 数据口径（交易日标签以数据为准，不取墙上时钟）

| 内容 | 数据源 | 口径 |
|---|---|---|
| 指数点位/涨跌幅/成交额 | 腾讯 qt.gtimg.cn 快照 | 实时；两市成交额 = 上证 + 深证成交额 |
| 行业板块涨跌幅 + 主力净额 | Tushare `moneyflow_ind_dc` | **东财板块口径**（与资金流监控同源），日频；与申万/Wind 口径数值不可直接对应 |
| 大盘主力资金流近 20 日 | akshare `stock_market_fund_flow` | 东财口径，日频，子进程隔离 |
| 涨跌家数/涨停家数 | akshare `stock_market_activity_legu` | 乐咕，子进程隔离 |
| 榜单板块近 5 日净额 | Tushare `moneyflow_ind_dc(ts_code=...)` | 当日流入/流出榜各前 5，逐板块求和 |

各源**独立失败**：某源挂掉只让对应板块为空，整份报告仍然产出。
节假日/周末请求时自动落在最近一个交易日（Tushare 截面的最新 trade_date）。

## 每日自动生成与防错过机制

调度作业 `sector_rotation_report`：**工作日 15:40 主生成 + 16:40~23:40 每小时补跑**
（A 股 15:00 收盘，等东财/Tushare 日频结算留 40 分钟余量）。
注册于 `src/scheduler/registry.py`，执行分支在 `src/scheduler/jobs.py`。

Celery Beat **不补跑**错过的触发，所以"新鲜"不靠单一调度时点，靠四道防线：

1. **落伍判定**（核心）：`service.is_stale()` 比对「落盘交易日」与
   「应有交易日」——后者来自本地交易日历 `latest_complete_trade_date()`
   （节假日天然正确，零网络）。落盘 < 应有 = 落伍。
2. **每小时补跑**：16:40~23:40 的 cron 触发先查 `is_stale()`，已最新则
   零成本跳过（一次内存比较），落伍才付一轮取数 —— 覆盖"15:40 时主机关机，
   晚上开机"的场景（开机后下一个整点 40 分自动补上）。
3. **启动自检**：`main.py` lifespan 里 `_check_sector_rotation_at_startup`
   （延迟 60s 后台执行）——重启是用户唯一确定会做的动作，与行情同步
   启动自检同一解法；覆盖"补跑窗口也错过"（如半夜才开机）。
4. **读取自愈**：`/report` 与 `/report.html` 发现落盘落伍时同步补生成
   （15 分钟 TTL 防轮询放大取数）——用户打开页面看到的永远是最近
   收盘交易日的报告，不会静默展示旧数据。

落盘：`data/sector_rotation/report_YYYYMMDD.{json,html}`。

## 研判是规则生成，不用 LLM

`service.narrate()` 是纯函数：结论（普跌/普涨、主力净额、风格差、
资金连续性提示）完全由报告里的数字推导，可复现、可单测，
不存在"数字与文字对不上"的幻觉风险。页面与 JSON 均标注
`narrative_engine=rule-based-v1` 与"非投资建议"。

规则阈值（`service.py`）：上涨家数占比 ≥65% 普涨 / ≤35% 普跌；
上证50 与创业板指涨跌幅差 |≥1.5pct| 判风格显著；
涨幅 >1% 且主力净流出 → "情绪博弈方向"；当日流入但 5 日累计为负 →
"按单日反弹对待"。

## 前端

「资金流监控」一级页签内的**二级页签**（`SectorRotationTab.tsx`）：
工具条（交易日切换 / 重新生成 / 新窗口打开）+ iframe 嵌 `report.html`。
选择二级而非一级页签的理由：与"钱往哪走"同一语义族、不占用一级
页签名额、不新增套餐权限配置；若日后要提级，参照主线挖掘的路径
（App.tsx 加 TL + view 分支 + visible_views 配置）。
